ResearchSignal Table для Excel

Добавьте надстройку в Excel один раз. После этого вкладка ResearchSignal будет доступна в Excel под вашей учётной записью.

1. Скачайте установочный файл

Для настольного Excel на Windows установщик скачает и проверит манифест, скопирует путь к нему и откроет Excel. В Excel останется выбрать «Загрузить мою надстройку» и подтвердить файл.

Скачать установщик для Windows

Скачайте также вторую часть установщика в ту же папку, затем дважды щёлкните CMD-файл. Окно останется открытым; журнал появится на рабочем столе. Установщик не меняет настройки безопасности Windows или Office.

Excel в браузере или установка вручную

Скачать манифест вручную, затем в Excel выберите Главная → Надстройки → Дополнительные надстройки → Мои надстройки → Загрузить мою надстройку и укажите скачанный XML.

2. Завершите добавление в Excel

  1. Откройте Excel и любую книгу.
  2. Выберите Главная → Надстройки → Дополнительные надстройки. В некоторых версиях этот пункт находится в меню Вставка → Надстройки.
  3. Откройте Мои надстройки или Дополнительно, затем нажмите Загрузить мою надстройку.
  4. Выберите скачанный ResearchSignal-Table.xml и подтвердите загрузку.

После установки откройте вкладку ResearchSignal на ленте и нажмите Open Table.

Если пункта «Загрузить мою надстройку» нет: ваша организация могла отключить самостоятельную установку. Попросите администратора Microsoft 365 добавить надстройку из этого манифеста через раздел «Интегрированные приложения» в центре администрирования.

Как удалить

В Excel откройте Надстройки → Мои надстройки, найдите ResearchSignal Table и выберите меню надстройки, чтобы удалить её.
